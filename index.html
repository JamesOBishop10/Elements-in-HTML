Main Content Area

This is the primary content of the page, containing the most important information for users.

<div>
Generic container for grouping elements
When to use:
When you need a block-level container without semantic meaning
Avoid when:
If a more meaningful element like <section> or <article> makes more sense

<span>
Generic inline container
When to use:
When styling or scripting a small part of text inside a larger element
Avoid when:
If the container should be block-level
Live Example

This paragraph contains highlighted text and more highlighted text using span elements.

<p>Text with <span class="highlight">highlighted</span> content</p>
<section>
Represents a section of content
When to use:
When the content groups related elements into a distinct section
Avoid when:
If the grouping doesn't contribute to document structure
Live Example

About Our Services

This section contains information about our company services and offerings.

<section><h2>Section Title</h2><p>Section content...</p></section>

Article Element

<article>
Represents a standalone piece of content
When to use:
When the content could be independently distributed (e.g., blog post, news article)
Avoid when:
If the content doesn't stand alone

<aside>
Sidebar content related to the main content
When to use:
When including tangential or supplementary info
Avoid when:
If the content is part of the main flow of information
Live Example

Did you know?

HTML5 introduced semantic elements to improve document structure and accessibility.

<aside><h3>Related Info</h3><p>Sidebar content...</p></aside>
<header>
Container for introductory content
When to use:
When including navigation, branding, or introductory info for a section or document
Avoid when:
If it's not introductory content

<footer>
Container for closing content or metadata
When to use:
When including author details, copyright, related links at the end of a document or section
Avoid when:
If the content belongs elsewhere in the layout
Live Example

© 2025 HTML Reference Guide. All rights reserved.

Contact: info@example.com

<footer><p>© 2025 Company Name</p></footer>
<nav>
Holds navigation links
When to use:
When grouping main site navigation links
Avoid when:
If the links are just inline, or not part of a major navigation system
Live Example
Home About Services Contact
<nav><a href="#home">Home</a><a href="#about">About</a></nav>
<main>
Holds the central content of the page
When to use:
When marking content that is the main focus of the document
Avoid when:
If the content is supplementary
